Privacy Policy

Last updated: 15 August 2026

This policy covers the Sleepy Dreams Music website and the personal automation tool used by its operator to prepare and publish videos to the @anysleepydreams YouTube channel.

Who operates this

This is an individually operated project, not a company. It is not a public application or service offered to other users — the automation tool is used only by its own operator to manage a single YouTube channel that the operator owns.

What data this website collects

This website is static and does not use cookies, analytics, tracking scripts, or forms. It does not collect any personal data from visitors.

What data the automation tool accesses

The automation tool uses the YouTube Data API (via OAuth 2.0) to upload videos, set video titles/descriptions/thumbnails, and schedule publish times on the operator's own YouTube channel. It also uses third-party stock-footage and AI-music-generation APIs (Pexels, ElevenLabs) to prepare video content before upload; those requests do not include any end-user or viewer data.

No data belonging to other people (viewers, subscribers, commenters) is collected, stored, or shared. The tool only ever acts on the operator's own channel and account.

Google API Services User Data Policy

This tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained through the YouTube API is used solely to operate the automation tool for the operator's own channel and is not shared with or sold to any third party, and is not used for advertising purposes.

Data retention

OAuth tokens and API keys used by the tool are stored locally on the operator's own computer and are not transmitted anywhere other than to the relevant API providers (Google, Pexels, ElevenLabs) to perform the actions described above.
